網站資訊

本網站介紹基金會及相關藝術活動。音樂會資訊見各活動頁；購票受外部票務平台條款約束。支持及合作安排另以書面約定。本網站不構成投資要約，亦不承諾財務回報或捐贈可抵稅。

隱私

上述基金會負責本網站及 office@viyaf.org 來函所涉及的個人資料處理。本網站由 GitHub Pages 託管；託管服務商可能處理 IP 位址、瀏覽器資訊及請求時間等技術資料，以提供及保護網站。我們不加入追蹤 Cookie、分析程式或廣告像素。已發布媒體隨網站提供，字體使用您裝置已安裝的字型。影片僅在您選擇播放時開始。

查詢與通信

當您聯繫我們時，您提供的資訊用於處理來函及其後相關事宜。處理依情況基於回覆查詢的正當利益、應您要求進行的締約前措施或適用法律義務。來往資料依用途需要及適用保存義務留存。外部連結將前往適用其自身隱私說明的服務。

您的權利及圖片查詢

您可聯繫 office@viyaf.org，在適用範圍內要求查閱、更正、刪除、限制處理、反對處理或資料可攜。亦可向奧地利資料保護機關申訴。如對已發布圖片有疑問，請提供所在頁面及說明，以便處理。
